# Local Development

## Run Server
```bash
python3 -m http.server 8081
```
Access at: http://localhost:8081

## Version Management

**IMPORTANT:** Before committing to GitHub, bump the version number in both:
1. `index.html` - Main feedback form (in h1 title in parentheses)
2. `admin/index.html` - Admin dashboard (in subtitle paragraph)

Use semantic versioning (e.g., v2.0.1 → v2.0.2 for patches, v2.0.2 → v2.1.0 for features)
